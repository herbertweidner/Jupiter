-------------------------
These are two MATLAB programs designed to identify phase-modulated gravitational waves in the frequency range of approximately 2 µHz to 90 µHz.
An application is described at https://www.researchgate.net/publication/411205842_Gravitational_Radiation_from_Jupiter
The required data consist of 10-year records from barometers, archived by the DWD (German Weather Service).
The file q00183.mat contains the data series for weather station 00183 and serves as an example here.
The files q2000.txt and p2010.txt list the file paths where the records are stored on the computer.
Using this data, the program Jupiq8.m calculates the properties of the gravitational waves and the modulating planets several hundred times.
The program JupRichtung.m is used to determine the direction of the gravitational wave source.
